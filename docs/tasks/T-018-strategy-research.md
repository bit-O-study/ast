## 결정 사항 (데이터 수집·성과 조회 전 고정)
- 사용자 요청: 인터넷 분석법 조사 후 실제 빗썸 시세 비교. 기존 운영 전략/설정 변경 없음. 연구 프로세스에서만 후보를 등록하며 영구 전략 목록에는 추가하지 않음.
- 후보3개: momentum (7일·21일 수익률 양수, 종가>60MA, 60MA 6봉 기울기 양수), channel (직전55봉 최고가 종가 돌파, 현재 제외20봉 상대 거래량>=1), squeeze (직전 봉 밴드폭이 직전60개 밴드폭 하위20% 이하, 현재 상단 돌파·폭 확대, 상대 거래량>=1.2). 4시간봉으로 고정. 일봉 원전 그대로 복제한 전략이 아닌 자체 가설.
- score/defensive/breakout 비교군, 후보 포함 총6개. 기존 공통 진입계획·손절·분할매도·BTC국면 필터 동일. 분할매수 꺼짐, 초기1천만원/포지션100만원/위험2%.
- 공개 마감봉6000개 목표(약1000일), BTC/ETH/XRP. 시각 정렬·중복·간격·OHLCV 검사 실패 시 연구 중단. 캐시+SHA256 보존.
- 시간순 60%/20%/20% 구간. 각 구간은 현금으로 재시작, 경계 앞 준비200봉을 제공. 최종20%는 이전 T015~017에서 본 데이터와 겹침: 순수 미관찰 검증 아님. 임계치 재조정/종목 사후 제외 없음.
- 비용2개: 편도 수수료0.04%+슬리피지0.05%, 스트레스0.25%+0.10%. 계정 요율 미확인 가정.
- 후보 승격의 필요조건: 후반2개 구간 모두 3종목 평균 수익률이 score보다 높음, 각 구간 최소2종목 순손익 양수, 후보 전체 후반 거래30건 이상, 각 구간 평균MDD가 score의1.2배 이내, 스트레스에서도 각 후반 구간 평균 순손익 양수. 모두 만족해도 제한 모의 검토 후보일 뿐 운영 자동 승격 안 함.
- 전체표/탈락 사유 공개. 계좌수익률·거래당 순수익률·PF·MDD·거래수·시장노출·동일100만원 매수보유 비교. 최대 투자금 확대나 레버리지로 수익 부풀리지 않음.

## 공개 근거
- https://www.nber.org/papers/w24877 : 암호화폐 시계열 모멘텀 연구. 자체7일/21일 조합 성과 보장 아님.
- https://www.aqr.com/Insights/Research/Journal-Article/Time-Series-Momentum : 장기 모멘텀 연구. 원전12개월/다자산 선물과 본 연구4시간봉 현물은 다름.
- https://www.bollingerbands.com/bollinger-band-rules : 밴드 접촉만으로 반전 매매하지 않음, 연관 지표 중복 경계.
- https://www.turtletrader.com/rules/ : 20/55일 돌파 원칙 참고. 본 후보55봉은 원전55일과 다름, 청산도 기존 앱 규칙.
- https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf : 많은 시도 중 최적 결과 선택의 과적합 위험. 후보/기준 사전 고정, 검증 재사용 공개.
