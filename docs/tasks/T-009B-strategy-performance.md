# T-009B 전략 기록 및 월별 성과

담당: Codex · 사용자 위임(2026-10-25) · 리뷰 대기

## 결정 사항
사용자가 전략 기록 저장 서버 코드와 성과 화면 구현을 이어 진행하도록 위임했다. 매매 판단/주문/손익 계산은 변경하지 않는다. 진입 시 strategy: {id, name} 사본을 저장하고 청산에 전달한다. ID가 없으면 null, 이름이 없으면 ID를 표시한다. 기존 기록은 추정하지 않는다. 월별 집계는 저장된 ID별로 합산하며 이름은 해당 월 최신 거래의 기록을 사용한다. CSV 끝에 전략 ID와 이름을 추가한다.

### 2026-10-26 후속: 전략별 성과 지표
- 사용자 지속 개발 지시에 따라 동일 허용 파일에서 전략 표의 승률·평균 청산 순손익·수익계수(PF)를 추가한다.
- 승률은 양수 청산 건수/전체 유효 청산 건수. 기존 실패 열은 0원 포함 정의를 유지한다. PF는 양수 순손익 합/음수 순손익 절댓값 합이며 0원은 이익·손실 합에 포함하지 않는다. 음수 청산이 없고 이익이 있으면 ‘손실 없음’, 양수·음수 모두 없으면 ‘—’로 표시한다. 평균 이익/평균 손실과 구분한다.
- 월·전략 필터 범위와 저장된 순손익을 사용한다. 새 의존성·매매 코어 변경 없음. 단위 테스트 및 3개 폭×2개 테마 브라우저 확인 후 전체 테스트 실행.
- 검증 완료: 전용 21/21, 전체 180/180, 브라우저 162/162. 양수·음수·0원·빈 월·KST 경계/전략 필터와 PF 정의 검증.
