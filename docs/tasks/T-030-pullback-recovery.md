# T-030 상승국면 눌림 회복

사용자 지속 연구 지시에 따른 후속 가설. 국면만으로 잦게 진입한 T029의 비용 손실을 줄이기 위해 회복 시점만 진입한다. 결과 조회 전 사전 고정한다.

## 사전 고정 조건
- 공통 BTC20일 상승국면 필터 유지, 후보3개: RSI14가30 이하에서30 초과 회복, 종가가 볼린저 하단 이하에서 하단 초과 회복, 20이평이60이평보다 높은 상태에서 종가20이평 상향 회복.
- 직전/현재 마감봉으로만 판정한다. 점수 문턱 대신 회복 조건 사용, 손절 관리용 기존 점수는 보존. 새 기간/임계치/종목별 파라미터 탐색 없음.
- 손절·목표가·보유기간·100만원 상한·체결 모두 기존 공통 함수. 운영 등록 없음.
- T018 고정 시세3종목×3구간·200봉 준비, 기본0.04%+슬리피지0.05%, 스트레스0.25%+0.10%. 비교군score/persistence 포함90행. 반복 관찰 자료 탐색임을 명시.
- 기존 엄격 기준: 기본 후반2구간 각 종목 양수 및score 초과, 기간별 평균MDD<=score1.2배, 스트레스 기간별 평균양수, 후반 총30거래 이상. 합격만 미관찰 자료 검증 후보.

## 완료 기준
- 임계 경계·교차 이벤트·미래봉 비참조 단위검증, 전체 npm test.
- 후보9개 조합 Trader 리플레이, 기본3시장 npm run verify(T029와 공통 실행 코드 불변이면 같은 검증 기록 사용).
- 모든 후보 결과/미달 이유/원본SHA 기록. 실시간 연결/운영 경로 미변경으로 V3 제외.
