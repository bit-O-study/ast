## 결정 사항 (신규 후보 성과 조회 전 고정)
- 직전 목표 턴은 T020 72개 비교/220개 테스트/9개 리플레이로 진전. 현재 파일 확인 결과 동일하며 중기BTC 미충족 상태.
- 먼저 T020 persistence의 전체3시장×3구간 손실을 최종 청산 이유/거래 원장으로 분해한다. 손실 거래만 선별한 임계치 최적화는 하지 않는다.
- 이미 개별 검토한 진입 지속성과 보유·재진입 가설의 상호작용을 별도 실험한다. 비교군 score, persistence. 후보4개: persistence+patient(MAX_HOLD_BARS120), persistence+runner(120봉/1차25%/2차8R), persistence+cooldown(손실후6봉), persistence+efficiency(20봉 양의 순변동/총절대변동>=0.3). 조합을 추가하거나 임계치를 재조정하지 않는다. T019/T020 관찰에 따른 후속 탐색임을 공개한다.
- T018 동일 고정6000봉3시장/3연속구간/준비200봉/2비용, 최초손절·자금·노출 상한 동일. 총108개. 기존 시세 재사용이며 독립 검증 아님. 일일/누적손실 차단 미적용인 단일진입 백테스트의 기존 제한 명시.
- 판정은 T020 그대로: 후반 두 기간 각각 모든 종목 기본비용 양수·score 초과, 평균MDD<=score1.2배, 스트레스 평균양수, 후반 총30건 이상. persistence 비교군 대비 개선도 따로 공개한다. 일부 개선은 성공 아님.
- 통과한 후보만 아직 평가하지 않은2024년 이전 기간으로 추가 확인한다. 여기서 탈락한 후보는 옛 시세를 더 조회해 구제하지 않는다. 모든 결과·탈락 이유 보존, 운영 자동 배포 없음.
