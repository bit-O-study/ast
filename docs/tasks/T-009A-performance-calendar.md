## 결정 사항

- 기존 /api/trades 전체 청산 거래만 사용. 청산 시각 exitAt을 KST 날짜로 묶고 pnl을 합산. 수수료 추가 차감 없음. 0원은 기존 계약대로 실패.
- 부분 매도 손익은 최종 청산일에 합산되며 보유분 평가손익/백테스트는 제외. 현재 모드·전략을 과거 거래에 소급하지 않음.
- 성과 탭: 월 이동/이번 달, 월 순손익/거래 수/성공·실패 수, 7열 달력, 날짜 선택 거래표. 모바일 셀에는 금액 요약, 상세 합계는 날짜 선택 시 제공.
- 초기 월/선택일은 현재 KST. 조회 전 로딩, 빈 월과 조회 실패를 구분. 실패 시 기존 수치 보존 및 갱신 경고. 잘못된 집계 입력은 제외 건수 표시.
- 날짜 범위 1970~9999년. 월 이동 경계에서는 버튼 비활성. 런타임 의존성/API/매매 코어 변경 없음.

## 월별 CSV 후속 범위
