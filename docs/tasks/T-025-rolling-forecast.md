## 결정 사항 (성과 조회 전 고정)
- T024 108개 비교/234개 테스트/12개 리플레이는 진전. 현 파일 확인. 필터를 계속 강화하는 대신 관측된 가격으로만 기대수익을 갱신하는 별도 가설을 검토한다.
- 후보3개: 최근200개4시간 마감봉에서 ridge 회귀로 다음6/18/42봉(1/3/7일) 로그수익률을 추정한다.3봉 지속 점수 신호가 있고 예측 로그수익률이 현재 수수료·슬리피지 손익분기점을 초과할 때 진입. 기존 청산/초기위험/자금 유지. 예측기간이 강제 보유기간은 아님.
- 입력6개 고정: 종가/20MA-1,20MA/60MA-1, RSI/100, MACD히스토그램/ATR, 거래량/현재제외20봉평균-1, ATR/종가. 각 학습행은 과거 j봉 마감 특징, 정답은 log(c[j+h]/o[j+1]). 지표 준비60봉, j+h<=현재인덱스-1인 표본만 학습(현재 봉 정답 제외). 정규화 평균·분산도 학습행에서만 계산.
- 목적식 sum((y-Xw)^2)+10*sum(w^2), 절편 무규제, 정규화 후 고정10. 정상방정식 소규모 직접 풀이, 외부 의존성 추가 없음. 학습행80개 미만/비유한 값은 진입 거부. 최근200봉 고정 창으로 백테스트·Trader 동일 입력. 모델/창/특징/하이퍼파라미터를 결과에 맞춰 조정하지 않는다.
- 예측 비용 기준 log((1+fee)*(1+slip)/((1-fee)*(1-slip))). 각 비용 조건에서 별도 진입 판정. 목표수익은 고정기간 수익이며 실제 공통 청산 손익과 같다고 주장하지 않는다. 겹치는 라벨 때문에 학습행 수가 독립 표본 수는 아니다.
- 기존 score/persistence와3후보,90개. T018 동일 시세/구간/준비200봉/비용/자금. T020 이후 엄격 전종목 양수·score 초과/낙폭/비용/30거래 기준 유지. 관찰자료 탐색이며 독립 검증 아님. 통과 시에만 미관찰2024년 이전 자료 추가 확인, 탈락 시 미조회. 운영 배포 없음.
