## 결과

### 1. 계좌 투입 비중이 수익률을 약 1/40로 희석한다
- score 전략의 9개 구간×종목, 총 192거래 **전부가 MAX_POSITION_KRW=100만원 상한으로 체결**된다. RISK_PER_TRADE 2% 계산값이 항상 상한보다 커서 위험 기준 크기는 실제로 작동하지 않는다.
- 보유 시간 비율은 14~27%. 1천만원 계좌의 평균 실투입은 2~3%다.
- 그래서 거래 단위 평균 +1%가 계좌로는 0.1% 단위로만 보인다. 점수 전략 계좌 수익률이 -0.7~+3.4%에 머무는 주원인이다.
- 상한만 풀면(위험 2%) 수익과 낙폭이 함께 커지되 부호가 바뀌는 구간이 있다(XRP 초기 +2.8% → -7.8%). 손절 폭이 좁은 거래에 큰 금액이 실려 손실이 커지기 때문이다. **상한을 단순히 푸는 것은 개선이 아니다.**

### 2. 수수료 0.25%라면 score 전략의 우위가 사라진다 (민감도)
> 2026-10-27 사용자가 계정 요율 0.04%를 확인했다. 아래는 요율이 오를 때의 민감도로만 본다.

연구 기본 비용(편도 0.04%)은 API 무료 이벤트 요율이다. 이벤트는 2026-09-06에 종료됐고, 계정 적용 요율은 확인되지 않았다(T-015 메시지). 운영 기본값 FEE_RATE는 0.25%다.

| 3종목 평균 | 초기 | 중기 | 최근 |
|---|---:|---:|---:|
| 수수료 0.04% | +1.84% | +0.94% | +0.14% |
| 수수료 0.25% | +0.56% | +0.01% | **-0.45%** |

T-018~T-025의 "기본" 판정은 모두 0.04% 가정 위에서 이뤄졌다. 실제 요율이 0.25%라면 후반 두 구간에서 점수 전략 자체가 손익분기 이하다.

- 수익 대비 낙폭(실요율): 중기 0.65, 최근 0.31. 같은 비용의 score는 0 이하.

### 한계 (반드시 같이 읽을 것)
- 이미 관찰한 자료 3구간이다. 미래 성과를 보장하지 않는다.
- 결과가 한두 종목에 쏠려 있다. 중기는 ETH(+72%), 초기는 XRP(+160%)가 끌어올렸고 BTC·XRP 단독은 중기에 손실이다. 분산이 수익의 핵심 조건이다.
- 전액 투입 기준 MDD 20~32%다. 계좌 일부만 쓰면 수익과 낙폭이 거의 비례해서 줄어든다(예: 30%만 쓰면 MDD 약 6~10%).
- 손절가가 없는 규칙이라 AGENTS.md의 "손절가·목표가 같은 함수" 구조와 맞지 않는다. 채택하려면 설계(포트폴리오 단위 보유 규칙)를 새로 정해야 한다.
- 3종목 동시 보유는 T-007(다중 코인 + 포트폴리오 위험 한도)이 선행돼야 한다.
