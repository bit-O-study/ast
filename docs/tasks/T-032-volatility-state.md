# T-032 변동성 상태별 점수 진입

사용자 지속 연구 요청. 비용을 넘는 가격 움직임과 손절 위험의 관계를 구분하기 위해 기존 score 진입을 변동성 상태별로 비교한다. 성과 조회 전에 조건을 고정한다.

## 사전 고정 조건
- 변동성=마감 ATR14/종가. 직전120개(4시간×120=20일) 마감 변동성 중앙값과 현재값을 비교한다. 현재 봉은 중앙값 표본에서 제외한다.
- 후보2개: score 진입 중 현재 변동성<중앙값(낮음), 현재 변동성>=중앙값(높음). 180봉 이상 준비. 점수·기간·경계값 최적화 없음.
- 기존 score 신호/공통 손절·목표가·국면·재진입 규칙 유지. 위험2%/매수100만원 상한은 역사적 비교 기준 유지. 서버300만원 설정의 성과로 주장하지 않는다.
- T018 고정3종목·3연속구간·준비200봉, 기본0.04%+슬리피지0.05%, 스트레스0.25%+0.10%. score/persistence 비교군 포함72행.
- 기존 기준: 기본 후반2기간 각 종목 양수 및score 초과, 기간별 평균MDD<=score1.2배, 스트레스기간별 평균양수, 후반30거래 이상. 통과한 후보만300만원 규모/미관찰 자료 추가 검증 대상으로 삼는다.
- T027 2020~2023 자료는 이번 탐색에 읽지 않는다. 이전 결과를 본 시세의 후속 탐색이며 독립 검증 아님.
