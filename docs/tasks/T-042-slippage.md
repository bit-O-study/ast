# T-042 실제 호가 기준 체결 비용(슬리피지) 측정

사용자 요청(2026-10-27): "수익률 더 연구해봐". 2017~2026 시세는 모두 관찰 자료가 됐다(T-041). 그래서 전략 대신 **실제 체결 비용**을 잰다. 모든 백테스트와 모의 브로커는 편도 슬리피지 0.05%를 가정했지만, 이 값은 실측한 적이 없다.

## 방법
- 빗썸 공개 API `/v1/orderbook`·`/v1/ticker`만 조회한다. 주문은 내지 않는다.
- 기준가는 모의 브로커와 같은 직전 체결가(`trade_price`)다.
  - 매수: 1회 금액(200만·300만)만큼 매도 호가를 낮은 가격부터 소진한 평균 체결가 ÷ 기준가 − 1
  - 매도: 같은 금액어치 수량을 매수 호가에 높은 가격부터 소진한 평균 체결가로 1 − 평균 ÷ 기준가
- 15초 간격 20회(약 5분), BTC·ETH·XRP. 재현: `node scripts/measure-slippage.mjs 20 15`

## 결론
1. **실제 체결 비용은 편도 약 0.02~0.03%로, 가정(0.05%)보다 작다.** 평상시와 봉 마감 직후 모두 그렇다. 종목별로는 BTC가 가장 작고, XRP는 매수 쪽이 가정과 비슷하다.
2. 그래서 지금까지의 수익률 추정은 보수적이었다. 민감도 표로 보면 6.3년 기준 약 **+5~9%p**를 덜 잡은 셈이다.
3. **지정가 주문(T-006)으로 아낄 수 있는 몫은 편도 0.02~0.03% 정도로 작다.** 미체결 위험과 구현 복잡도를 생각하면 우선순위를 낮춘다.
4. 모의 브로커와 연구의 SLIPPAGE 0.05%는 **그대로 둔다.** 보수적으로 잡는 편이 실거래 전환 때 기대를 부풀리지 않는다.
5. 한계: 하루 두 번 7분 남짓 표본이다. 급등락 때는 비용이 커질 수 있다. 실거래로 넘어가면 실제 체결가와 직전 체결가의 차이를 기록해 다시 확인한다.
