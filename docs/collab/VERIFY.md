# 검증 기록

모든 기능은 여기에 검증 결과를 남겨야 `완료`가 됩니다. 사용자 결정 (2026-10-23): **만든 기능을 모의투자로 계속 검증하면서 개발한다.**

## 검증 단계

| 단계 | 방법 | 언제 필요한가 |
|---|---|---|
| V1 단위 테스트 | `npm test` 전체 통과 | 모든 작업 |
| V2 리플레이 검증 | `npm run verify -- 1500 KRW-BTC,KRW-ETH,KRW-XRP` 통과 (실매매 코드 = 백테스트, 오류 0) | 매매 루프·전략·포지션·주문·브로커를 건드린 작업 |
| V3 실시간 모의투자 | `MODE=paper npm start`로 실제 시세에서 연속 운영, 오류·이상 동작 없음 | 실시간 경로(시세 연결, 알림, 감시, 주문 실행)를 건드린 작업. 기간은 작업 명세에 적음 |
| V4 실제 서비스 확인 | 실제 빗썸·텔레그램 등에 연결해 수동 확인 | 외부 서비스와 통신하는 작업 |

- V2 보고서는 `docs/verify/날짜_코인_봉_전략_필터.md`에 자동 저장됩니다.
- V3는 집 PC 세팅 전까지 개발 PC에서 짧게(최소 1회 봉 마감 포함) 돌리고, 세팅 후 장기 운영으로 이어 갑니다.
